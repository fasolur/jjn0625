1任务一 · 提示词工程师（⭐⭐）
把 4 条需求"翻译"给 AI，生成 new Swiper('#wySw4', {...}) 配置，至少迭代 2 轮。
  • 需求① 无缝循环（loop）
  • 需求② 3.2 秒自动翻页，且手动操作后不停止（autoplay.delay + disableOnInteraction）
  • 需求③ 圆点分页器可点击（pagination.clickable）
  • 需求④ 初始效果为 cube（effect）
第 1 轮 · 我的提示词（故意写得笼统，看 AI 会不会漏）
🧑 我帮我用 Swiper 写一个轮播配置：new Swiper('#wySw4', {...})，要循环播放、自动播放每 3.2 秒翻一页、带圆点分页器、效果用 cube。
🤖 AI 第 1 轮回答好的，配置如下： 
var swiper4 = new Swiper('#wySw4', {
  loop: true,
  autoplay: { delay: 3200 },
  pagination: { el: '.swiper-pagination' },
  effect: 'cube'
});
❌ 实测发现的错误：① autoplay 少了 disableOnInteraction: false —— 手一动它就永久停了；② pagination 用了默认 '.swiper-pagination' 且没写 clickable: true —— 圆点既找不到容器也不能点。
第 2 轮 · 我的提示词（逐条点名参数）
🧑 我你上一版有两个问题：1）autoplay 只写了 delay，我手动拖动后自动播放就停了，需求要求手动操作后不停止，请补上对应参数；2）我页面的分页器容器 id 是 #wyPag4，不是默认的 .swiper-pagination，而且需求要求圆点可以点击跳转。请重新给完整配置，并用一句话解释每个参数。
🤖 AI 第 2 轮回答（验证通过 ✅）抱歉，补全如下： 
var swiper4 = new Swiper('#wySw4', {
  loop: true,                                  // 无缝循环：最后一张再往后翻会回到第一张
  autoplay: {
    delay: 3200,                               // 每张停留 3200 毫秒 = 3.2 秒
    disableOnInteraction: false                // 关键：用户手动拖动/点击后，自动播放继续
  },
  effect: 'cube',                              // 初始切换效果为 3D 立方体
  speed: 800,                                  // 切换动画时长 800ms
  pagination: { el: '#wyPag4', clickable: true } // 指定分页器容器，圆点可点击跳转
});
验证结论（截图 + 一句话）：把第 2 轮配置原样粘进下方 #wySw4，逐项实测—— ① 拖到最后一张继续翻能回到第一张，loop 生效；② 不动手时每 3.2 秒自动翻页，手动拖过之后再等 3.2 秒仍然继续自动翻（第 1 轮的代码会在手动后永久停止，对比明显）；③ 点圆点能跳到对应 slide，clickable 生效；④ 切换呈立方体旋转，cube 生效。四项全部通过 ✅

2任务二 · creative 仿写「电影墙」（⭐⭐⭐）
课堂讲了 6 种 effect，第 7 种 creative 自学：对照官方示例 257-effect-creative.html，为演示四新增第 7 个按钮。
关键对话 · 问 creativeEffect 的 transform 写法
🧑 我Swiper 的 effect: 'creative' 怎么用？我看了官方 demo 257-effect-creative.html，里面的 creativeEffect.prev / next 里 transform 用了 ['120%', 0, -500] 这种数组，我想做一个"电影选片墙"：上一张缩小、往左移、带一点角度挂在墙上；下一张放大、从右边推进来。帮我写配置。
🤖 AIcreative 的 prev / next 各描述"离开视口的上一张 / 等待进场的下一张"的 transform，数组是 [x位移, y位移, z位移]： 
creativeEffect: {
  prev: {  // 上一张：缩小左移 + 逆时针挂角度 → 像贴在墙上的旧海报
    translate: ['-108%', '-4%', -260],
    rotate: [0, 0, -12],
    scale: 0.72,
    opacity: 0.55
  },
  next: {  // 下一张：放大右移进场 → 像新海报推到面前
    translate: ['106%', '0%', -140],
    rotate: [0, 0, 8],
    scale: 1.18,
    opacity: 0
  },
  perspective: true,     // 开启 3D 透视
  limitProgress: 2       // 最多渲染前后各 2 张，省性能
}
注意：translate 里带百分号的项，百分号是相对 slide 自身的宽/高；rotate 第三个分量是绕 z 轴的 2D 旋转角度（deg）。

  cfg.creativeEffect = {

  };
}
✍️ 用自己的话回答：prev / next 的 transform 各控制什么？
prev 描述的是"当前这张 slide 翻页后变成上一张时"的状态——我把它设为缩小到 0.72 倍、左移出视口、逆时针转 12°，所以点"下一张"时，当前卡片就像被挂回左边墙上的旧海报；next 描述的是"即将进场的下一张在进场前"的初始状态——我把它设为放大 1.18 倍、停在视口右侧外面，切换时它从右边放大着推进来，像放映厅里被推到正前方的选片海报。一句话：prev 管"出去的样子"，next 管"进来的起点"。
🎤 答辩抽问备案：① transform 里的百分号是相对谁的？——相对slide 自身的宽度和高度：'106%' 表示往右挪一个 slide 宽度再加一点，z 轴的 -260 是像素；② 现场改 20 度：把 next 的 rotate: [0,0,8] 改成 rotate: [0,0,20]（或 prev 改 [0,0,20]），刷新后进场卡片会明显斜 20 度。

关键对话 · 新展品 slide + keyboard 配置
🧑 我两件事：1）给光影展加第六件展品「爱达·魔都号」（中国首艘国产大型邮轮，2024 年 1 月 1 日首航），图片我已用 AI 生成（16:9，images/aida-modu.jpg），帮我按现有 slide 结构写完整的 HTML；2）想让轮播支持键盘 ←/→ 翻页，Swiper 有这个功能吗？怎么配？
🤖 AI 第 1 轮slide 结构和三层骨架一样，照抄一份改内容即可；键盘功能叫 keyboard 模块： 
keyboard: { enabled: true }
❌ 实测发现问题：AI 没加 onlyInViewport，页面一滚动，按方向键会劫持按键、影响其它轮播和页面滚动。
🧑 我有一个问题：页面里还有别的轮播，这样写会让键盘全局被 Swiper 抢走。能不能只在轮播进入视口/获得焦点时才响应键盘？
🤖 AI 第 2 轮（验证通过 ✅）加 onlyInViewport: true，Swiper 只会在自己处于可视区域时才接管 ←/→： 
// 第六件展品 slide（结构与前五件完全一致）
<div class="swiper-slide">
  <img src="images/aida-modu.jpg" alt="爱达·魔都号">
  <div class="slide-cap">
    <h3>爱达·魔都号</h3>
    <p>首艘国产大型邮轮 · 2024 年 1 月首航</p>
  </div>
</div>

// keyboard 键盘控制（课堂上没讲过的能力）
keyboard: {
  enabled: true,          // 开启键盘 ← → ↑ ↓ 翻页
  onlyInViewport: true    // 只有轮播在视口内才响应，不劫持整页按键
}

🎤 答辩四连问备案：
① 这段代码什么意思？keyboard 模块监听 document 的 keydown；enabled 开启方向键翻页，onlyInViewport: true 表示只有当轮播滚进视口时才响应，避免劫持整页按键（这是我对 AI 第 1 轮答案的修正点）。
② AI 第一次给的哪里不对、你改了什么？AI 第 1 轮只给了 keyboard: { enabled: true }，实测页面一滚动按方向键就乱跳；我追问"能否只在视口内响应"，AI 补了 onlyInViewport: true，问题解决。
③ 新参数的作用？onlyInViewport 限定键盘事件只在轮播可见时生效；另外 slide 结构是标准三层骨架，第六件展品与前五件完全同构，仅 img 与文案不同。
④ 现场改 delay 并解释预期变化：给本展品加 autoplay: { delay: 5000, disableOnInteraction: false }，把 5000 改成 2000 → 每张停留时间从 5 秒变 2 秒，翻页节奏明显变快；数字是毫秒，改完刷新立即生效。
